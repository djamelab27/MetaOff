# Contributing

Contributions are welcome, especially small reproducible metadata fixtures and support for additional well-documented container fields.

1. Create a focused branch.
2. Add or update tests for behavior changes.
3. Run `npm test` and `npm run check`.
4. Avoid runtime dependencies, remote code, network access, and new Chrome permissions.
5. Never commit a real user's private photo as a test fixture; build synthetic binary fixtures instead.
